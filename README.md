# HQ Depth of Field

<p align="center">
  <img src="res/icon.png" alt="Dusklight Mod Template icon" width="220" />
</p>

Replaces the built-in depth of field for a high-quality effect, optionally blurring far-away objects slightly during normal gameplay, not just during cutscenes or cinematic moments.

**IMPORTANT: Set the built-in depth of field option to Off while this mod is enabled (Settings > Video > Post-processing > Depth of Field).**

Based on Jorge Jimenez's "NEXT GENERATION POST PROCESSING IN CALL OF DUTY: ADVANCED WARFARE" SIGGRAPH 2014 course notes.

`LLM Usage: AI assistance was used for the development of this mod, especially the wgsl shader.`
